# City Walk 随机路线骰子 · 广州版

解决出行选择困难的单页小工具：摇下骰子，让命运替你决定去哪、怎么走、干什么。

## 点链接直接玩

# [https://didididududuvery.github.io/citywalk-dice/](https://didididududuvery.github.io/citywalk-dice/)

手机、电脑浏览器打开即玩，无需登录、无需下载、无需安装任何东西。

## 这是什么

一套 3D 骰子，每颗骰子决定行程的一个维度，全部落定后生成一张可保存 / 分享的「漫游通行证」；路上打卡、计时，回来复盘、抽盲盒，把出发到分享做成一条完整闭环。走过的每一程会留在足迹册里，也能打包成一条链接让朋友复现同一套命运。

## 解决什么痛点

| 观察到的真实痛点 | 本工具的解法 |
| --- | --- |
| 周末想出门却选不出去哪，攻略软件信息过载，越刷越纠结 | 一次摇骰同时定下去哪、怎么走、干什么，把决策成本压缩到一次点击 |
| 现成攻略是"必去清单"，排得太满，执行像完成任务、压力大 | 用随机命运替代最优解，行程轻量、带惊喜，没有"必须打卡"的负担 |
| 普通随机工具只给一个目的地，不解决怎么去、做什么 | 多颗骰子分别决定主题、地点、规则、任务、限制，结果是完整方案而非一个点 |
| 随机给一个地铁站或片区，出站后不知道具体去哪 | 公园、社区、美食、随机版都绑定真实地点并附就近地铁，随机但可落地 |
| 完全独立随机容易摇出互相矛盾的组合，方案不可执行 | 冲突协调自动排除矛盾项，一键开摇和手动重摇都会触发，不占用摇动次数 |
| 手机出门中途刷新或切后台，行程记录和照片全丢 | 状态、打卡照片、评分与计时自动存本机，回来接着玩 |
| 玩到第 5 次又摇到同一个公园，惊喜感归零，且没有任何累积感 | 足迹册记录每程并集章；最近 3 次去过的地点自动避开，不足 6 面时从全城地点池补足 |
| 分享出去只是一张图，朋友看完就结束，没法一起玩 | 命运链接把整局编码进 URL，对方打开即只读复现；配「我也摇一次」和现成的播报文案 |

## 创新点

- 用"命运骰子"替代推荐算法：不追求最优解，把决策本身变成游戏和内容。
- 多维度骰子组合，而非常见的单点随机目的地，一次给出可执行的完整行程。
- 随机结果绑定真实地点与就近地铁，兼顾惊喜感和可落地性。
- 通行证 + 计时 + 打卡 + 复盘卡 + 盲盒小确幸卡，覆盖"出发、记录、点评、分享"全链路。
- 足迹册把一次性玩具变成会累积的东西：历史、集章进度、12 周日历、往期复刻，都在本机完成。
- 零后端的可复现分享：一局结果压进 URL hash，无需账号、数据库或服务端，朋友打开就能玩同一局。
- 剧本与城市均可扩展，一套机制可系列化复用。

## 怎么玩

1. 选剧本：随机版 / 公园版 / 社区版 / 美食版，再选 i 人或 e 人模式，可加开「新鲜事挑战」。
2. 点「一键开摇」，也可以单独点某颗骰子重摇，每颗最多摇 3 次；「命运加码」会把任务卡换成一组疯狂任务（i 人版零社交），整局仅 1 次。
3. 全部落定后系统自动协调矛盾组合，再点「生成漫游通行证」，保存或分享图片即可出发。
4. 点「开始」记录行程用时（切后台、锁屏也准）；路上给每个完成项拍照或定位打卡，可删除重传。
5. 打卡过半后抽「今日盲盒」，生成「今日小确幸收集卡」。
6. 走完回来在「行程复盘」里打星、选本程亮点，生成复盘卡。
7. 通行证下方点「复制命运链接」发给朋友；对方打开会看到只读复现，点「我也摇一次」即可自己开一局。「复制今日命运播报」会连文案带链接一起写好，可直接发小红书。
8. 页尾「足迹册」看累计次数、集章进度、最近 12 周日历；每条往期都能「复刻这局」重新分享。
9. 点「重新开一局」清空整局（足迹保留）；进度自动存在本机，刷新页面不丢。

## 功能清单

| 模块 | 内容 |
| --- | --- |
| 骰子 | 主题、目的地/出发站、行路规则、任务卡、限制条件，开启后多一颗新鲜事骰子；每颗 3 次上限、彩蛋面 |
| 剧本 | 随机版（6 个主题全部绑定真实目的地）、公园版（14 个真实公园）、社区版（12 个真实街区）、美食版（12 条美食街） |
| 模式 | i 人零社交 / e 人轻度社交，独立任务池；命运加码也分 i / e 两套疯狂任务 |
| 冲突协调 | 只在真正冲突时重摇，按骰子合并规则、最多两轮；主题变化时随机版目的地自动同步；结果用独立提示条说明 |
| 通行证 | Canvas 生成，含编号、日期、模式、行程用时与全部安排，高度随内容自适应，可保存 / 分享 |
| 计时 | 基于时间戳，切后台不漏秒；随整局重置 |
| 打卡 | 拍照（自动压缩）或定位，显示坐标、进度与删除重传；打卡过半才能抽盲盒 |
| 复盘卡 | 1-5 星评分、本程亮点、赛博评语，重摇后自动同步内容 |
| 小确幸卡 | 今日盲盒 + 打卡/照片统计，可单独保存 / 分享 |
| 存档 | 全部进度存 localStorage，刷新自动恢复；清浏览器数据会清空 |
| 足迹册 | 每生成一张通行证记一程（日期 / 剧本 / 地点 / 主题 / 星级 / 打卡数 / 盲盒），最多 100 条；累计次数、解锁地点数、平均星级、12 周日历、集章进度条；最近 3 次地点自动避开，往期可一键复刻 |
| 命运链接 | 6 个结果 + 剧本 / 模式 / 编号 / 日期 / 评分 / 用时编码进 `#f=`；对方打开为只读复现（不写存档、不记足迹、不可摇骰），可保存通行证或点「我也摇一次」；移动端支持系统分享文本 |
| 分享 | 移动端 Web Share API 直接分享图片或播报文案，桌面端下载 PNG / 复制文本；含 og 分享封面 |
| 存档管理 | 足迹册内显示 localStorage 占用估算，可单独「清空足迹」或「清空本局存档（含照片）」 |

## 技术说明

- 单个 HTML 文件，原生 HTML / CSS / JavaScript，无框架、无后端、无外部依赖；`og-cover.png` 为社交分享封面。
- 所有站点、公园、社区、街区数据内联在 JS 中；把 HTML 文件存到本地可离线打开。
- 通过网址访问仍需联网（未接 Service Worker）；进度只存在本机浏览器，不上传服务器。
- 存档分两个 key：`citywalk-dice:v2` 存当前一局，`citywalk-dice:history:v1` 存足迹历史；照片压到 1000px / JPEG 0.78 后存 base64。
- 命运链接用 `TextEncoder` → base64url 编码，纯前端解码复现；`file://` 打开时链接自动指向线上 Pages 地址。
- 响应式布局，适配桌面与移动端；支持键盘操作与 `prefers-reduced-motion`。
