# City Walk 随机路线骰子 · 广州版

解决出行选择困难的单页小工具：摇下骰子，让命运替你决定去哪、怎么走、干什么。

## 点链接直接玩

# [https://didididududuvery.github.io/citywalk-dice/](https://didididududuvery.github.io/citywalk-dice/)

手机、电脑浏览器打开即玩，无需登录、无需下载、无需安装任何东西。

## 这是什么

一套 3D 骰子，每颗骰子决定行程的一个维度，全部落定后生成一张可保存的「漫游通行证」，直接发朋友圈或小红书。骰子之间带轻量冲突协调，会自动排除"湖畔发呆 + 走满 6000 步"这类互相矛盾的组合，同时保留随机的惊喜感。

## 解决什么痛点

| 观察到的真实痛点 | 本工具的解法 |
| --- | --- |
| 周末想出门却选不出去哪，攻略软件信息过载，越刷越纠结 | 一次摇骰同时定下去哪、怎么走、干什么，把决策成本压缩到一次点击 |
| 现成攻略是"必去清单"，排得太满，执行像完成任务、压力大 | 用随机命运替代最优解，行程轻量、带惊喜，没有"必须打卡"的负担 |
| 普通随机工具只给一个目的地，不解决怎么去、做什么 | 多颗骰子分别决定主题、地点、规则、任务、限制，结果是完整方案而非一个点 |
| 随机给一个地铁站或片区，出站后不知道具体去哪 | 公园、社区、美食、随机版都绑定真实地点并附就近地铁，随机但可落地 |
| 完全独立随机容易摇出互相矛盾的组合，方案不可执行 | 轻量冲突协调自动排除矛盾项，且不占用摇动次数、不破坏随机感 |
| 结果只是一行字，没有保存和分享的欲望 | 通行证与复盘卡做成可下载的成品卡片，形成出发、记录、分享的闭环 |

## 创新点

- 用"命运骰子"替代推荐算法：不追求最优解，把决策本身变成游戏和内容。
- 多维度骰子组合，而非常见的单点随机目的地，一次给出可执行的完整行程。
- 随机结果绑定真实地点与就近地铁，兼顾惊喜感和可落地性。
- 通行证加复盘卡，覆盖"出发、计时、点评、分享"全链路，天然适配社交传播。
- 剧本与城市均可扩展，一套机制可系列化复用。

## 怎么玩

1. 选剧本：随机版 / 公园版 / 社区版 / 美食版，再选 i 人或 e 人模式，可加开「新鲜事挑战」。
2. 点「一键开摇」，也可以单独点某颗骰子重摇，每颗最多摇 3 次。
3. 全部落定后生成「漫游通行证」，保存图片即可出发。
4. 用内置计时器记录行程，走完回来在「行程复盘」里打星、选亮点，生成复盘卡。

## 功能清单

| 模块 | 内容 |
| --- | --- |
| 骰子 | 主题、出发站点、行路规则、任务卡、限制条件，开启后多一颗新鲜事骰子 |
| 剧本 | 随机版、公园版（14 个真实公园）、社区版（12 个真实街区）、美食版（12 条美食街） |
| 模式 | i 人零社交 / e 人轻度社交，独立任务池，含低概率彩蛋面 |
| 通行证 | Canvas 生成，含编号、日期、模式、行程用时与全部安排，可下载 |
| 复盘卡 | 1-5 星评分、本程亮点、赛博评语，可单独保存 |
| 冲突协调 | 自动重摇矛盾组合，不占用摇动次数；协调失败给出提示 |

## 技术说明

- 单个 HTML 文件，原生 HTML / CSS / JavaScript，无框架、无后端、无外部依赖。
- 所有站点、公园、社区、街区数据内联在 JS 中，离线也能打开。
- 响应式布局，适配桌面与移动端。

## 系列规划

广州首发，深圳、佛山等城市按评论区点菜解锁，机制可直接复用。
